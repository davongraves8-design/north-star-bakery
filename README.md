# North Star Bakery

Touchstone 4 builds on the same three pages, warm color palette, navigation, image, and contact form from Touchstone 3.

## Included changes

- Home page: save or remove favorite products; selections persist in localStorage and restore after a refresh.
- Contact page: JavaScript validates name, email, message length, and an optional pickup date, with messages beside fields and entered values preserved.
- Accessible status messages, selected button states, and keyboard focus indicators.
- Hero image and narrow-screen layout fixes.

The contact form is a browser demonstration. A successful validation preview does not send an order or email.

## Upload these files to the existing GitHub repository

1. Extract the Touchstone 4 ZIP on your computer.
2. Open the existing north-star-bakery repository.
3. Choose Add file, then Upload files.
4. Upload index.html, about.html, contact.html, style.css, script.js, README.md, and the assets folder at the repository root. Do not upload only the ZIP or nest everything inside another folder.
5. Commit the changes. Keep the repository public and retain the existing GitHub Pages settings.
6. Open the published site after deployment, refresh, and test favorites and the contact form.
7. Open the Word submission, enter your full name, confirm both project links, and complete the two remaining online verification checklist items.
8. Submit the completed Word document to Sophia. The updated project files belong in GitHub.

## Quick verification

On Home, save Custom Cakes, refresh, and confirm the selection returns. Remove it and refresh to confirm removal persists.
On Contact, use A as the name, bad-email as the email, and Need cake as the message; click Review Request and confirm the three messages.
Correct the entries and confirm the preview succeeds. Enter a past pickup date to verify the date check.
Check Home, About, and Contact on desktop and phone.
